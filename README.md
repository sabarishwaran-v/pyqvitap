<p id="description">PyqVitAp is a student-built archive of 5000+ VIT-AP previous year question papers directly sourced from DSpace. It provides a fast and centralized way to search filter preview and download question papers by course exam type semester and academic year. The project is built to make finding VIT-AP PYQs simple and accessible for students bringing papers from multiple academic years and courses together in one place.</p>

<h2>🧐 Features</h2>

Here're some of the project's best features:

*   🔎 Smart Course Search Search VIT-AP question papers instantly by course code or course title.
*   📚 5000+ Question Papers Access a growing collection of VIT-AP previous year question papers sourced from DSpace and student contributions.
*   🎯 Advanced Filtering Filter papers by course exam type academic year semester and slot.
*   📝 CAT & FAT Papers Find papers for CAT-1 CAT-2 CAT and FAT examinations.
*   👀 In-Browser PDF Preview Preview question papers directly in the browser without downloading them.
*   ⬇️ Direct Downloads Download individual question papers with standardized readable filenames.
*   📦 Bulk ZIP Downloads Select multiple papers and download them together as a ZIP archive.
*   📌 Pin Subjects Pin frequently used subjects for faster access during exam preparation.
*   📅 Exam Schedule Integration Browse upcoming examination schedules and quickly find papers associated with courses and slots.
*   📤 Student Contributions Students can contribute recent question papers to help expand the collection.
*   🛠️ Paper Requests Request papers that are currently unavailable in the collection.
*   📱 Progressive Web App Install PyqVitAp on supported mobile and desktop devices for an app-like experience.
*   🔗 Direct DSpace Sourcing A large portion of the collection is sourced directly from the publicly accessible VIT-AP DSpace repository.

<h2>🛠️ Installation Steps:</h2>

<p>1. Clone the repository</p>

```
git clone https://github.com/sabarishwaran-v/pyqvitap.git cd pyqvitap
```

<p>2. Install dependencies</p>

```
pnpm install
```

<p>3. Create the environment file</p>

```
cp .env.example .env
```

<p>4. Configure environment variables</p>

```
Add the required MongoDB Cloudinary Upstash Redis Gemini API and application URL values to .env.
```

<p>5. Start the development server</p>

```
pnpm dev
```

<p>6. Open the application</p>

```
http://localhost:3000
```

<p>7. Create a production build</p>

```
pnpm run build pnpm start
```

<h2>🍰 Contribution Guidelines:</h2>

Contributions are welcome! PyqVitAp is a student-built open-source project and contributions from students and developers are encouraged. Before contributing: 1. Fork the repository. 2. Create a new branch for your change. 3. Make your changes while following the existing project structure and coding style. 4. Test your changes locally before submitting them. 5. Run the available type checks and linting checks. 6. Commit your changes with a clear and meaningful commit message. 7. Push your branch and open a Pull Request. Good contributions include: - Bug fixes - UI/UX improvements - Search and filtering improvements - Performance improvements - Accessibility improvements - Documentation improvements - New student-focused features - Improvements to the paper browsing experience Please do not: - Commit .env files or API credentials - Commit private data or database dumps - Commit large PDF collections or internal datasets - Modify or redistribute university documents outside the scope of the project - Introduce unnecessary dependencies or unrelated changes For major feature changes opening an issue first is recommended so the approach can be discussed before implementation. Please keep Pull Requests focused on one feature fix or improvement whenever possible.
