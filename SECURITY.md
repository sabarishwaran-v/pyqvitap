# Security Policy

## Reporting Security Issues

We take the security and privacy of the **PyqVitAp** project seriously. If you believe you have discovered a security vulnerability or sensitive information exposure, please report it responsibly.

### How to Report

Please **do not** report security vulnerabilities, credentials, or potential exploit steps via public GitHub Issues, Discussions, or Pull Requests.

Instead, please send an email to:
📧 **pyqvitap@gmail.com**

In your report, please include:
- A description of the vulnerability and its potential impact.
- Clear, safe steps to reproduce the issue (proof of concept code or request samples).
- Any recommendations or suggestions you have to resolve the issue.

We will review your submission and work to address confirmed security concerns as quickly as practical.

## Guidelines

- **Never publicly expose credentials:** Do not share database connection strings, API secrets, private keys, or tokens in public forums.
- **Respect user data:** Please avoid performing destructive testing, bulk data exfiltration, or denial-of-service attempts against production infrastructure.
